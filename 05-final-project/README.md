# Python学习项目 - 文件批量重命名工具

## 项目简介
一个用于批量重命名文件的Python工具，支持多种重命名模式。

## 功能特性
- 按序号重命名
- 按日期重命名
- 查找替换重命名
- 添加前后缀
- 预览重命名效果

## 技术栈
- Python 3.10+
- pathlib
- os
- datetime

## 安装
```bash
pip install -r requirements.txt
```

## 使用方法
```bash
python renamer.py --help
```
